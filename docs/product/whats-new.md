# Что нового

Изменения документации по версиям, от новых к старым. Версия сайта указана в его исходниках; поведение платформы описано для версий, развёрнутых вместе с документацией.

## 0.10.2

- Новая навигация: в шапке разделы «Начало», «Configurator», «Справочник», «Руководства», «API и агенты», «Архитектура», «Сервисы» и «Raph»; у каждого раздела свой сайдбар.
- В «Начале» — маршрут новичка от знакомства с продуктом до первых руководств.
- Добавлены оглавления [справочника](/reference/), [руководств](/guides/) и [сервисов](/services/) и эта страница.
- Адреса страниц не изменились.

## 0.10.1

- [Примеры документов всех типов](/agents/document-examples): проверенный документ для каждой коллекции и порядок создания.
- [Вертикальный срез](/agents/vertical-slice): связанный набор документов от Type до нескольких Composition, таблица «когда нужен / когда нет».
- Исправлены примеры `filterView` в [Composition](/reference/composition), добавлены правило и коды compiler.
- Описаны версия формата и обязательные поля при создании документов, чтение длинных ресурсов MCP по частям и ограничение персональных токенов для профилей аутентификации.
- Уточнены mock-режим Query, цепочки Converter, шаги Action и узлы навигации.

- [Авторинг Source и SFC](/agents/authoring), точная грамматика выражений, [Store](/reference/store), [общий контракт field](/reference/field-contracts), [event-hooks Composition](/reference/composition-events) и [матрица возможностей](/reference/capabilities).
- [Контракты API пакетов](/reference/contracts/), собранные из исходников, с указанием происхождения.

- [MCP](/agents/mcp): ресурсы с документацией, фасеты, просмотр и восстановление ревизий, история коммитов.
- Примеры в документации стали абстрактными.
