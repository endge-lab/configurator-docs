# TimelineGroup

`<TimelineGroup>` размещает несколько [TimelineChart](./timeline-chart) вертикально. При `sync="time"` Vue-адаптер связывает положение и зум через `TimelineChart.linkViewports`. Прокрутка строк остаётся независимой. Для общего зума, навигации по времени и возврата скрытой панели достаточно декларации группы в SFC.

## Пять синхронизированных панелей

Шаблон **Timeline Group** в Configurator содержит пять графиков на учебных данных. Верхний график показывает шкалу, четыре нижних строятся из списка ресурсов и используют встроенный в Configurator пресет `demo-resource-load`. В конечном приложении используйте зарегистрированный там пресет либо уберите `preset` и `settings`.

Этот вариант показывает ту же структуру с данными из props и без пресета:

```vue
<script setup lang="ts">
const props = defineProps<{
  overview: unknown
  resources: Array<{ id: string, title: string, timeline: unknown, hidden?: boolean, collapsed?: boolean }>
  range: { start: number, end: number }
}>()

const ports = definePorts({
  emits: {
    visibleWindow: event<TimelineRangeChangedEvent>({
      from: { ref: 'group', event: 'rangeChanged' },
    }),
  },
})
</script>

<template>
  <TimelineGroup ref="group" sync="time" splitter :label-width="180" :range="props.range">
    <TimelineChart key="overview" title="Обзор" :data="props.overview"
                   :columns="[{ id: 'title', field: 'title', title: 'Ресурс' }]"
                   :height="240" :options="{ ungroupedPanel: { enabled: false } }" />
    <TimelineChart for="resource in props.resources" :key="resource.id"
                   :title="resource.title" :data="resource.timeline"
                   :columns="[{ id: 'title', field: 'title', title: 'Ресурс' }]"
                   :hidden="resource.hidden" :collapsed="resource.collapsed"
                   :height="140" :min-height="80" :max-height="360"
                   :options="{ timeScale: { enabled: false }, ungroupedPanel: { enabled: false } }" />
  </TimelineGroup>
</template>
```

Передайте один объект Timeline в `overview` и четыре ресурса в `resources`, чтобы получить пять панелей. Объекты используют одну и ту же временную систему координат. Если нужны общие пределы навигации, задайте совместимые `options.timeRange.min` и `max` во всех графиках. Единый `timezone` в настройках помогает согласовать подписи шкал.

## Атрибуты группы

| Атрибут | Значение |
| --- | --- |
| `sync` | `time` связывает панорамирование и масштаб времени, `none` оставляет их независимыми. По умолчанию `none` |
| `leader` | Ключ ведущего графика для `sync="time"`. Если ключ не задан или участник недоступен, временное окно группы можно менять с любого графика. Например, `leader="overview"` относится к `key="overview"` |
| `range` | Явное окно `{ start, end }` в миллисекундах Unix, где `end > start`. Новое значение переводит участников в указанное окно с учётом границ каждого графика |
| `label-width` | Общая ширина левой области в px, по умолчанию 160. Ноль скрывает левую область |
| `splitter` | Добавляет ручки между видимыми панелями |
| `ref` | Ссылка на группу для маршрутизации `rangeChanged` |

Группа принимает прямые дочерние теги `TimelineChart`. Используйте уникальный стабильный `key` среди участников, для повторения указывайте `for` и `:key` по идентификатору записи. Внешняя обёртка вокруг всей группы допустима. При изменении состава Vue-адаптер связывает доступные экземпляры заново. Добавленный или вернувшийся график получает текущий временной диапазон синхронизированной группы. Один видимый участник остаётся рабочим графиком.

### Ширина левой области и шкала

Группа приводит суммарную ширину колонок каждого участника к `label-width`, сохраняя их относительные размеры. Изменение общей ширины при перетаскивании границы колонки применяется к остальным участникам. Это выравнивает начало области времени. Чтобы оставить подписи только сверху, задайте `options.timeScale.enabled: false` для нижних графиков.

### Сплиттер и видимость

Ручка меняет высоту панели **над** собой между её `min-height` и `max-height`. Соседняя панель сохраняет свою высоту, а группа при необходимости прокручивается. На ручке работают клавиши ↑ и ↓ с шагом 10 px, с Shift шаг составляет 40 px, Home устанавливает минимальную высоту. Размер хранится в открытом экземпляре группы по ключу панели.

- `hidden` скрывает график целиком.
- `collapsed` сворачивает график до заголовка. Пресет с `compact: true` может отобразить под заголовком компактную полосу загрузки высотой 32 px. При разворачивании возвращаются высота панели и окно синхронизированной группы.
- `options.ungroupedPanel.enabled: false` скрывает только нижнюю внутреннюю панель задач без группы.

### Загрузка по диапазону

`rangeChanged` передаёт `TimelineRangeChangedEvent` с `start` и `end`. Группа публикует изменения, вызванные пользовательской навигацией, и отсекает повторную рассылку от ведомых графиков. При непрерывном зуме или прокрутке может приходить несколько изменений. Подключите `onEvent('timeline', 'visibleWindow')` к runtime-алиасу компонента в [Composition](/reference/composition-events). Обработчик может сохранять диапазон или запрашивать данные на окно. При дорогом запросе объединяйте близкие изменения в обработчике и проверяйте актуальность ответа перед записью данных. Если задача обновляет только данные, оставьте текущий viewport у группы.

## Visual и Preview

Создайте **Timeline Group**, чтобы получить форму настроек группы и список графиков. Через Visual можно переключить синхронизацию, задать ключ ведущего графика, левую ширину и сплиттер, затем выбрать панель и настроить её поля. У повторяемой панели форма редактирует общий тег `TimelineChart`. Состав участников приходит из списка, указанного в `for`. Для изменения привязок, выражений или структуры шаблона используйте Source.

Проверьте результат в Preview. При зуме с верхней и нижней панелей одна и та же отметка времени должна совпадать по вертикали. Измените ширину колонки и высоту сплиттером, скройте и верните одну панель, обновите набор задач. При наличии обработчиков проверьте `rangeChanged`, выбор задачи и фокус через [Action графика](./timeline-chart#событие-и-фокус-по-задаче). Для проверки данных Composition используйте [Runtime Preview](/configurator/runtime-preview-workspace).
