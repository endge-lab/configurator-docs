# Начало работы

Конфигуратор — веб-приложение для создания и редактирования конфигураций Endge. Его backend хранит документы, историю и назначения доступа. Для базовой установки нужны frontend конфигуратора, backend и PostgreSQL.

Конечное приложение, которое исполняет конфигурации через Endge Core, подключается отдельно. Оно не заменяет конфигуратор и не входит в минимальную установку редактора.

## Порядок настройки

1. [Установите frontend, backend и базу данных](./installation).
2. [Выберите способ аутентификации и источник прав](./authentication).
3. Настройте [OIDC для пользователей](./authentication/oidc) или [фиксированного пользователя для локальной разработки](./authentication/development).
4. Войдите в конфигуратор, выберите backend и рабочее пространство.
5. Перейдите к [основному рабочему процессу](./workflow): выбору документа, редактированию, проверке и сохранению.

## Репозитории

| Компонент | Назначение | Open source repository |
| --- | --- | --- |
| Configurator | Интерфейс редактора в браузере | [endge-lab/configurator](https://github.com/endge-lab/configurator) |
| Service Backend | API, документы, история, сессии и права доступа | [endge-lab/service-backend](https://github.com/endge-lab/service-backend) |
| Configurator Docs | Это приложение документации | [endge-lab/configurator-docs](https://github.com/endge-lab/configurator-docs) |

Документацию можно читать отдельно: её сервис не требуется для работы редактора. AI Workbench и генератор mock-данных также подключаются как дополнительные сервисы и не входят в базовый набор.

## Статус настройки внешних прав

::: warning Проект для согласования
OIDC-вход и локальное управление правами уже существуют. Внешнее управление правами через `endge-access.yaml`, переменную `ACCESS_CONFIG_FILE` и диалог «Мои права доступа» описано как проект следующего изменения. Эти возможности ещё не реализованы. Проверка текста предшествует изменению backend и frontend.
:::

Начните проверку предложения со страницы [«Аутентификация и права доступа»](./authentication), затем изучите [механику OIDC](./authentication/oidc) и [формат файла внешних прав](./authentication/access-configuration).
