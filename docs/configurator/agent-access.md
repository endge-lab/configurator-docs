# Доступ для агента и история документа

## Кнопка «Для агента»

Кнопка с иконкой робота в шапке IDE выпускает [персональный токен](/agents/tokens) для текущего workspace и готовит промпт для ИИ-агента. Кнопка видна после входа и выбора workspace любой роли: Viewer может выпустить токен на чтение.

Диалог «Доступ для агента» содержит две вкладки.

**Новый токен.**

- Имя — по умолчанию «Агент · <название workspace>», до 120 символов.
- Workspace — текущий, не меняется.
- Права — «Чтение» или «Запись». Запись недоступна Viewer. Флажки «Коммиты и релизы» и «Удаление» активны только при записи. «Коммиты» доступны только Admin workspace или Platform Admin, иначе флажок неактивен с подсказкой.
- Срок — «1 час», «1 день», «7 дней» или «Свой». Пресет длиннее предела backend недоступен, под полем показаны дата истечения и максимальный срок.

После «Создать токен» диалог показывает токен один раз. Токен замаскирован до префикса, его можно показать. Кнопка «Скопировать промпт» копирует промпт с полным токеном, «Скопировать токен» — только токен. Предпросмотр промпта показывает токен замаскированным. При закрытии диалога и при «Создать ещё» секрет удаляется из состояния; Configurator его не сохраняет и не пишет в журнал.

**Токены.** Список своих токенов: имя, статус (активен, истёк, отозван), префикс, workspace, права, срок, последнее использование. Platform Admin переключает «Мои / Все» и видит владельца. «Отозвать» спрашивает подтверждение в строке.

### Промпт

Промпт — русский текст для агента:

- адреса backend и API, workspace и заголовок `X-Endge-Workspace`;
- токен и правило передавать его в `Authorization: Bearer`, не записывая в файлы, журналы и коммиты;
- права токена и срок действия в UTC;
- ссылки на `llms.txt`, `llms-full/agents.txt`, `llms-full/reference.txt` и `llms-full/api.txt` этой документации;
- правила работы: читать документ и его `revision`, изменять через `PATCH` с `If-Match`, при `409` перечитывать, не обходить ответы `access_token_*`, не создавать коммиты и не удалять без просьбы пользователя, после правок попросить проверить Source в Configurator — backend Source не проверяет.

Для токена на чтение правила изменения заменяются запретом изменений: агент предлагает правки текстом. Ссылки на документацию строятся из `VITE_DOCUMENTATION_URL`. Если переменная не задана, промпт просит агента узнать адрес документации у пользователя и даёт ссылку на `<backend>/swagger/openapi3.yaml`.

## История документа

Раздел «История» в общих настройках документа показывает его ревизии от новых к старым: номер, операцию, автора и время. Правка агента отмечается бейджем «агент: <имя токена>». Если имени нет в ответе backend и токен не виден пользователю, бейдж показывает «агент: токен <8 символов id>».

История загружается страницами по 50 ревизий без снимков; «Показать ещё» догружает следующую страницу, ошибка догрузки не сбрасывает уже показанное. Для несохранённого документа раздел сообщает, что история появится после сохранения. Просмотра снимка и восстановления ревизии в разделе нет.
