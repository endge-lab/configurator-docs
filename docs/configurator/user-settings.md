# Настройки пользователей

Откройте **Настройки → Настройки пользователей**. Список показывает
пользователей с серверными настройками в текущем рабочем пространстве и контексте.
Чтобы сменить контекст, выберите нужные документы фасетов в футере Configurator.

| Роль в рабочем пространстве | Доступ к настройкам пользователей |
| --- | --- |
| Viewer | Просмотр списка и настроек |
| Editor | Просмотр и редактирование JSON |
| Workspace Admin и Platform Admin | Просмотр, редактирование JSON и сброс настроек |

## Как включить

В общих настройках рабочего пространства выберите **Хранилище настроек
пользователей → Endge Backend**, сохраните рабочее пространство и
перезапустите открытый контекст. Ту же настройку можно переопределить в
конкретном документе фасета. **Унаследовать** возвращает правило
предыдущего слоя. Кнопка **Открыть сохранённые настройки** открывает общую
вкладку с текущим контекстом Configurator.

| Хранилище | Поведение |
| --- | --- |
| Локальное хранилище | Текущее поведение браузера по умолчанию |
| IndexedDB | Локальное состояние workspace в браузере |
| Endge Backend | Серверное хранение поддерживаемых ключей и локальная очередь синхронизации |
| Отключено | Запись пользовательского состояния этого workspace отключена |

При переключении хранилища записи сохраняются в прежнем хранилище.
Историю серверных настроек в контексте с другим драйвером можно читать
из вкладки «Настройки пользователей». Личное состояние уровня приложения,
например тема, использует отдельный контракт.

## Редактирование и сброс

- Выберите пользователя и измените JSON в Monaco. **Справка по ключам**
  открывается справа по кнопке с иконкой книги. Разделитель меняет ширину панели. Повторное нажатие закрывает справку. В редакторе подсказки
  появляются при наборе или по `Ctrl+Space`. Справка и подсказки используют
  язык интерфейса.
- Нажмите **Сохранить JSON**. Удаление поля из объекта сбрасывает одну настройку.
  При параллельной правке проверьте конфликтный ключ перед повторным сохранением.
- Администратор может нажать **Сбросить у пользователя**, чтобы удалить его
  настройки в выбранном контексте.
  Кнопка с корзиной **Сбросить у всех** удаляет серверные настройки всех пользователей в этом
  же контексте. Диалог называет контекст и предупреждает о безвозвратном удалении.
  После сброса старые офлайн-правки не восстановят удалённые значения.

Серверный каталог содержит `endge.ui.zoom`, `configurator.date-format` и
`aodb.spp-tabs.workspace` для вкладок СПП. AODB восстанавливает сохранённые
вкладки при открытии СПП. Если их нет или список пуст, AODB открывает вкладки из
`spp-tabs-test.initialTabs` в порядке конфигурации. Для других ключей нужна
регистрация их формата и описаний. В приложении с серверным драйвером индикатор облака показывает
ожидающие записи, проблемы с подключением и конфликты.
