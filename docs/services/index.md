# Сервисы

Configurator работает поверх Service Backend; остальные сервисы подключаются дополнительно и не входят в базовую установку.

| Сервис | Назначение | Подробности |
| --- | --- | --- |
| Service Backend | Документы workspace, история, права, HTTP API и MCP-сервер | [Работа через API](/agents/), [MCP-сервер](/agents/mcp), [установка](/configurator/installation) |
| Mock Generator | Детерминированные данные по JSON Schema и временные потоки событий | [Mock Data service](/services/mock-data) |
| Справочники | Подключение внешних справочников к Vocab | [Справочники и внешние providers](/services/vocabs) |
| AI Workbench | Подготовка документации и workspace для AI-модели | [Общая схема](/services/ai-workbench/data-preparation) |
